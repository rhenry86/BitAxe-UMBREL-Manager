# Bitaxe Optimizer — Umbrel Community App

Upload this repository to a public GitHub repository, edit the two `YOUR_GITHUB_USER/YOUR_REPO`
references in `umbrel-store/bitaxe-optimizer/docker-compose.yml` and the metadata URLs, then
push to `main`. GitHub Actions publishes the Docker image to GHCR.

In Umbrel: App Store → ⋯ → Community App Stores → Add → enter your GitHub repository URL.
